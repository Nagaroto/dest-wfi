# Dependências

Este projeto utiliza **Python 3** e a biblioteca **Scapy**.

## Linux

Crie um ambiente virtual e instale o Scapy:

```bash
python3 -m venv .venv && .venv/bin/pip install scapy
```

Execute o projeto:

```bash
.venv/bin/python seu_script.py
```

## Windows

Instale o Python 3 e depois execute no PowerShell:

```powershell
py -m venv .venv; .\.venv\Scripts\pip install scapy
```

Execute o projeto:

```powershell
.\.venv\Scripts\python.exe seu_script.py
```
